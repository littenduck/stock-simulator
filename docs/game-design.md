# Stock Simulator — 游戏设计决策与核心功能

> 版本：v0.1（2026-11-11），由 20 个设计问题的回答整理而成。
> 本文件是**设计的唯一依据**；[implementation-plan.md](implementation-plan.md) 第 13 节按本文件修订了实现细节。

---

## 1. 一句话描述

**回合制股票 Roguelike**：每局 60 个交易日，从 30 家“真实公司的搞笑改名版”里随机抽 6 家，价格回放一段真实的历史行情；
每 10 天从 3 个天赋里选 1 个；靠“传闻 → 应验”的信息差做多、做空、加杠杆、挂限价和止损单，
争取最高净资产，刷新本地最高分。每局 10–20 分钟。

## 2. 20 个设计决策

| # | 问题 | 决定 | 对实现的影响 |
|---|---|---|---|
| 1 | 核心玩法 | **Roguelike，每局随机** | 种子、随机抽公司、天赋构筑、局外解锁 |
| 2 | 时间推进 | **回合制，按天推进** | 去掉实时时钟和速度档位；“下一天”按钮 / 空格键 |
| 3 | 单局时长 | **10–20 分钟** | 60 天 × 每天 10–15 秒 |
| 4 | 美术风格 | **简洁扁平 UI** | 一个 Theme + 图标素材包；不需要角色立绘 |
| 5 | 局内成长 | **天赋三选一** | 新增 `PerkDef` + `RunModifiers`（修饰器模式） |
| 6 | 单局结构 | **一路到底拼最高分**，没有中途淘汰 | 分数 = 第 60 天收盘净资产；中段靠天赋和新闻保持新鲜感 |
| 7 | 局外成长 | **解锁新内容**，不加数值 | 新增玩家档案（解锁记录 + 最高分），和单局存档分开 |
| 8 | 信息透明度 | **传闻 → 应验** | 新闻分两步：传闻（带可信度）→ 1–3 天后应验或辟谣 |
| 9 | 交易方式 | **市价、做空、杠杆、限价 / 止损单**全做 | 统一保证金规则；挂单队列；强制平仓 |
| 10 | 市场规模 | **30 家公司池，每局抽 6 家**，4 个行业（科技、太空、消费、金融），每局至少有 1 家太空或金融公司 | 用种子打乱公司池，取前 6 家 |
| 11 | 节奏 | **60 天，每 10 天选一次天赋** | 第 0、10、20、30、40、50 天各选一次，共 6 次 |
| 12 | 天赋数量 | **15 个，全部初始可用** | 局外解锁的内容改为角色、公司和难度（见第 5 节） |
| 13 | 语言 | **只做英文** | 仍然用 `tr()` 和 CSV（以后加语言不用改代码），但不需要中文字体 |
| 14 | 涨跌颜色 | **固定绿涨红跌** | 不做颜色设置；用 ▲ ▼ 箭头辅助色盲玩家 |
| 15 + 17 | 平台 | **先只做网页版** | Godot Web 导出（单线程），放 GitHub Pages / itch.io；Steam 以后再说 |
| 16 | 音频 | **可商用素材包**（如 CC0） | `audio/` 里放素材，并在 `CREDITS.md` 里注明来源 |
| 18 | 输入 | **鼠标 + 键盘快捷键** | 快捷键：空格 = 下一天，B / S = 买 / 卖，1–6 = 切换股票，Esc = 菜单 |
| 19 | 商业模式 | **先不定价；先本地测试，计划在 GitHub 开源免费玩**；以后可能上 Steam 并支持创意工坊 | 选开源协议；内容格式要考虑以后做 Mod（见第 7 节） |
| 20 | 排行榜 | **只做本地最高分** | 档案里保存前 10 名：分数、角色、难度、种子、日期 |

## 3. 核心游戏循环

```
            ┌──────────────── 一局（约 15 分钟）────────────────┐
            │                                                   │
 主菜单 ─► 选角色和难度 ─► 第 0 天：天赋三选一                 │
            │                    │                               │
            │                    ▼                               │
            │   ┌──► 看行情、看传闻 ─► 下单 / 挂单 / 取消挂单    │
            │   │                    │                           │
            │   │                    ▼                           │
            │   │          点“下一天”（空格）                    │
            │   │                    │                           │
            │   │                    ▼                           │
            │   │   新价格 → 挂单触发 → 传闻应验或辟谣            │
            │   │   → 利息和借券费 → 保证金检查（不够就强平）     │
            │   │                    │                           │
            │   │        是第 10/20/30/40/50 天？ ── 是 ─► 天赋三选一
            │   │                    │ 否                        │
            │   └──── 没到第 60 天 ◄─┘                           │
            │                    │ 第 60 天                      │
            │                    ▼                               │
            │        结算：分数 = 净资产 → 本地排行榜            │
            │                    │                               │
            └────────────────────┼───────────────────────────────┘
                                 ▼
                    检查解锁（新角色 / 公司 / 难度）─► 回主菜单
```

## 4. 核心功能清单（按优先级）

**P0 = 没有它就不是这个游戏；P1 = 第一个公开版本要有；P2 = 有时间再做。**

| 优先级 | 功能 | 说明 | 验收标准 |
|---|---|---|---|
| P0 | 回合制交易日 | “下一天”推进；每天价格变化 | 空格推进一天，图表新增一个点 |
| P0 | 市价买卖 | 按当天收盘价成交，有手续费 | 现金和持仓正确变化 |
| P0 | 随机市场 | 30 家公司池，每局按种子抽 6 家，再选一段这 6 家都有数据的真实时间窗口 | 同一个种子抽到的 6 家相同 |
| P0 | 传闻 → 应验 | 传闻带可信度，1–3 天后揭晓 | 应验时价格按幅度变化；辟谣时不变或小幅回调 |
| P0 | 天赋三选一 | 15 个天赋，6 次选择 | 选完后效果立刻生效并显示在天赋栏 |
| P0 | 结算和本地最高分 | 第 60 天结算，前 10 名 | 关掉网页再打开，排行榜还在 |
| P1 | 做空 | 持股可以是负数；每日借券费 | 股价下跌时空头赚钱 |
| P1 | 杠杆 | 现金可以借成负数；每日利息 | 最大杠杆受天赋影响 |
| P1 | 保证金和强制平仓 | 净值低于维持保证金时全部平仓 | 平仓后有明确提示，可以继续玩到第 60 天 |
| P1 | 限价单 / 止损单 | 挂单到第 60 天或手动取消 | 第二天价格触及时自动成交 |
| P1 | 角色 | 3 个起始角色，规则略有不同 | 不同角色开局资金或初始天赋不同 |
| P1 | 局外解锁 | 解锁角色、难度（公司解锁机制保留但暂时为空） | 满足条件后主菜单出现新选项 |
| P1 | 单局存档 | 每天自动存档，关网页后可继续 | 刷新页面后点“Continue”回到同一天 |
| P1 | 音效 / 音乐 | 素材包 | 买、卖、下一天、天赋都有反馈音 |
| P2 | 难度 2–5 | 类似“进阶”：手续费更高、传闻更假等 | — |
| P2 | 统计页 | 总局数、最佳交易等 | — |
| P2 | 种子输入 | 玩家输入种子，和朋友比同一局 | — |

## 5. 内容设计（第一版）

### 5.1 行业与公司（30 家，全部初始可用）

公司都是真实上市公司的搞笑改名版（名字是谐音梗，代码是缩写梗）。每个公司文件用 `history_key` 对应真实代码，价格回放
`data/market/history.csv` 里的真实日线（2022–2026，已按拆股调整）。一局随机选一段 60 个交易日的窗口，6 家公司用同一段日期，
开局价格就是窗口第一天的真实收盘价，另外显示约 30 天的真实赛前走势。新闻事件是虚构的传闻，叠加在真实走势上。

晚上市的股票（SanDisk 2025-02、SpaceX 2026-06、Intuitive Machines 2023-02）没有更早的数据，所以只出现在它们有数据的窗口里。
抽公司的顺序：先抽 6 家，再选窗口；如果抽到的 6 家里没有太空或金融公司，就把最后一家换成随机的太空或金融公司。

| 行业 | 公司：游戏代码（名字，真实代码） |
|---|---|
| 科技（11） | NVDO（Nvideo，NVDA）、AND（Advanced Nano Device，AMD）、BVGO（Brovago Comm，AVGO）、MUN（Mucron，MU）、SNDH（Sandish，SNDK）、MRBL（Marbble，MRVL）、MHDR（Macro Hard，MSFT）、PPLE（Pineapple，AAPL）、FOGO（Foogl，GOOGL）、MEGA（Mega，META）、PLBR（Polarbear，PLTR） |
| 太空（4） | SPCZ（SpaceZ，SPCX）、RKLP（Rocket Lap，RKLB）、FSTS（Fast Spacemobile，ASTS）、LUNA（Lunatic Machine，LUNR） |
| 消费（12） | AMZG（Amazing，AMZN）、TZLA（Tezla，TSLA）、RIBN（Ribbon，RIVN）、LBIC（Lubric Motor，LCID）、NUTX（Nutflix，NFLX）、BOBX（Boblox，RBLX）、GMB（Game Blip，GME）、AAC（AAA Cinema，AMC）、CSGO（Costgo，COST）、SDUX（Starducks，SBUX）、KEKO（Keko Cola，KO）、POPS（Popsi Cola，PEP） |
| 金融（3） | BAIT（Coinbait，COIN）、HOOK（Robinhook，HOOD）、LOFI（Lofi，SOFI） |

公司解锁暂时关闭：现在 30 家都是现实公司的改名版，全部初始可用（每家的 `unlock_id` 都为空，`Profile` 不再发放 `company_*` 解锁）。机制本身保留，以后加入新的搞笑虚构公司时，给它设置 `unlock_id` 并在 `Profile.record_run` 里发放对应 id 即可。

名字是玩笑，仅用于游戏内；公开发布前要再确认改名是否合适，以及行情数据的再分发条款（见 `CREDITS.md`）。

### 5.2 天赋（15 个，按稀有度抽取权重：普通 60% / 稀有 30% / 传奇 10%）

| 稀有度 | 天赋 | 效果 |
|---|---|---|
| 普通 | Low Fees | 手续费 −50% |
| 普通 | Savings Account | 正现金每天 +0.05% 利息 |
| 普通 | Early Bird | 传闻提前 1 天出现 |
| 普通 | Fact Checker | 显示传闻的真实可信度区间 |
| 普通 | Stop Guard | 止损单不收手续费 |
| 普通 | Sector Fan | 选一个行业，该行业的传闻可信度 +15% |
| 稀有 | Margin Account | 最大杠杆 +1×（基础 1×） |
| 稀有 | Cheap Borrow | 借券费和融资利息 −50% |
| 稀有 | Diversifier | 同时持有 4 只以上股票时，每天净值 +0.1% |
| 稀有 | Dividend Hunter | 多头持仓每天 +0.03% 分红 |
| 稀有 | Second Opinion | 每次天赋选择多 1 个选项（四选一） |
| 传奇 | Insider Friend | 每 10 天有 1 条传闻保证为真，并标记出来 |
| 传奇 | Iron Hands | 第一次触发强平时免疫，改为警告 |
| 传奇 | Compounder | 结算分数 ×1.1 |
| 传奇 | Market Maker | 买卖都没有手续费，限价单成交价更优 1% |

### 5.2.1 传闻（新闻事件）

传闻在 `data/news/*.tres` 里，文案在 `localization/news.csv`（`NewsEventDef`），共 64 个模板：

| 类型 | 数量 | 说明 |
|---|---|---|
| 全市场 `all` | 4 | 加息、降息、大涨、大跌，影响所有公司 |
| 行业事件 | 16 | 科技、太空、消费、金融各 4 个，影响该行业的所有在场公司 |
| 抽签事件 `pick_*` | 4 | 目标写成 `any`，从该行业的在场公司里随机抽一家 |
| 单只股票事件 | 40 | 目标是某个代码，只有这家公司在本局的 6 家里才会出现 |

规则：每天每个模板按 `daily_chance` 掷骰，同一天最多出 1 条（`NewsDirector.MAX_PER_DAY`）；出现后冷却 `cooldown_days` 天。
传闻 1–3 天后揭晓：真则按 `total_impact` 在 `duration_days` 天里逐步生效，假则按 `denial_impact_ratio` 反向小幅修正。
可信度（玩家看到的）围绕真实概率加噪声；Fact Checker、Sector Fan、Insider Friend 这些天赋会改变显示或真实率。
文案固定用 “Rumor: ... is said to ...” 的口吻，不声称真实发生过的事。

### 5.3 角色（1 个初始 + 2 个解锁）

| 角色 | 开局 | 解锁条件 |
|---|---|---|
| Rookie | $10,000 现金，没有特殊规则 | 初始可用 |
| Day Trader | $8,000；开局自带 Low Fees；最大杠杆 +1× | 完成任意 1 局 |
| Value Investor | $12,000；不能做空；多头分红翻倍 | 单局净资产达到 $20,000 |

### 5.4 难度

难度 1 初始可用；用某个难度完成一局后解锁下一级（P2）。每一级累加一条惩罚，例如：
手续费 +50% → 传闻真实率 −10% → 每日波动 +20% → 维持保证金更高 → 只能选二选一。

## 6. 平台与发布

- **第一阶段：网页版**。Godot Web 导出，用**单线程**模式：GitHub Pages 和 itch.io 都不需要特殊的服务器响应头。
  - 渲染器必须用 **Compatibility**（网页只支持这个）。
  - 存档：Godot 会把 `user://` 存进浏览器的 IndexedDB，清除浏览器数据会丢失（在设置页提示玩家）。
- **第二阶段（以后再定）**：Windows 桌面版、Steam、创意工坊。架构已经留好平台接口，不用大改。

## 7. 开源与以后的 Mod / 创意工坊

- **开源协议（还没定，建议）**：代码用 **MIT**；美术和音频按各自素材包的协议，统一写在 `CREDITS.md`。
- **Mod 格式提醒**：Godot 的 `.tres` 文件里可以嵌入脚本，**从玩家电脑加载别人的 `.tres` 有安全风险**。
  所以：游戏内置内容继续用 `.tres`（开发方便）；以后做创意工坊时，玩家内容改用 **JSON**，由一个 `ContentLoader` 转成同样的 `CompanyDef` / `PerkDef` / `NewsEventDef`。
  规则层只认这些类，不关心数据来自哪里，所以到时候只需要新增 loader。
